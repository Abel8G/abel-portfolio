Employee Management API

This project is a backend API developed as a practical way to learn server-side JavaScript. It works with employee data and demonstrates common API operations.

Watch the demo

What it does

  • Returns a list of employees.
  • Returns an employee by ID.
  • Creates a new employee.
  • Updates employee information.
  • Deletes employee records as the API is extended.
How I built it
  1. Set up a Node.js project.
  2. Created an Express.js server.
  3. Defined API routes and request handlers.
  4. Added JSON request handling and input validation.
  5. Practiced sending requests and checking responses.

Technologies: JavaScript, Node.js, Express.js

Project status: Learning project / in development.

PostgreSQL Employee Database

A practical database project focused on storing and managing employee information using PostgreSQL.

What I practiced

  • Creating tables and inserting records.
  • Retrieving and filtering employee data.
  • Updating records and returning changed data.
  • Sorting results and using LIMIT and OFFSET.
  • Working with database transactions.
How I practiced
  1. Created an employee database and table.
  2. Inserted employee records.
  3. Practiced SELECT, UPDATE, and other SQL statements.
  4. Used filtering, ordering, and pagination.
  5. Practiced transactions using BEGIN, COMMIT, and ROLLBACK.

Technologies: PostgreSQL, SQL

Project status: Learning exercises / in development.
